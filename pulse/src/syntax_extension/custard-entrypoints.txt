# Entry points for the syntax_extension unit itself.
#
# Unlike pulse/src/custard-entrypoints.txt, which lists *compiler* symbols and
# is passed to the compiler's build, this file is passed to this unit's own
# extraction with --custard_entrypoints.
#
# Everything here is called from another unit, so nothing inside this unit
# reaches it and it would be dropped.  See doc/ref/custard.md section 12.11.
#
# Blank lines and lines starting with `#' are ignored.

# PulseSyntaxExtension.ASTBuilder.fsti declares them and has no .fst, so that
# unit compiles them to external references this one has to define.  Nothing
# inside this unit calls them, so without an entry here they are dropped.
