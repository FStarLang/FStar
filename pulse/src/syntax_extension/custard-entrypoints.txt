# Entry points for the syntax_extension unit itself.
#
# Unlike pulse/src/custard-entrypoints.txt, which lists *compiler* symbols and
# is passed to the compiler's build, this file is passed to this unit's own
# extraction with --custard_entrypoints.
#
# Everything here is called from hand-written OCaml under pulse/src/ml -- the
# menhir grammars pulseparser.mly and FStarC_Parser_Parse.mly, and the driver
# PulseSyntaxExtension_Parser.ml.  A grammar's semantic actions are OCaml the
# extractor never sees, so nothing reaches these constructors and they would
# be dropped.  See doc/ref/custard.md section 12.11.
#
# Blank lines and lines starting with `#' are ignored.
