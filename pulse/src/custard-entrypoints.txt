# Compiler entry points the Pulse plugin needs.
#
# Custard compiles exactly what is reachable from its roots, and the roots of
# a compiler build are FStarC.Main.main plus src/custard/entrypoints.txt.  The
# plugin is a separate program linked against the compiler: a call from it
# into the compiler crosses a unit boundary, which is no request Custard can
# see when it builds the compiler, so a compiler definition that only the
# plugin uses is dropped unless it is listed here.
#
# This file is passed to the *compiler's* build with --custard_entrypoints,
# not to the plugin's -- the symbols have to be in the binary the plugin is
# loaded into.  See doc/ref/custard.md section 12.13.
#
# Blank lines and lines starting with `#' are ignored.

# Pulse.RuntimeUtils (pulse/src/syntax_extension)
FStarC.Errors.with_error_bound
FStarC.Errors.with_ctxs
FStarC.Syntax.Compress.deep_compress_uvars
FStarC.TypeChecker.Normalize.unfold_whnf'
FStarC.Syntax.Util.unlazy_as_t
FStarC.Syntax.Free.ord_ctx_uvar
FStarC.Syntax.Free.ord_univ_uvar
# Declaration-only since #4389, so nothing in the compiler reaches it;
# Custard synthesizes the body (section 21).
FStarC.Syntax.Syntax.uu___is_Unresolved_name

FStarC.FlatSet.elems

# FStarC.FlatSet.union is deliberately not here, and could not be: it takes a
# typeclass dictionary, which section 3.1 classifies Mono, and a root has no
# call site to specialize it at (error 364).  It does not need to be: the
# plugin calls it from F* (Pulse.RuntimeUtils), and those call sites are
# specialized in the plugin's own unit.  See doc/ref/custard.md section 12.13.

# PulseSyntaxExtension.  register_extension_parser and
# register_extension_tosyntax are extension hooks: the compiler declares them
# and never calls them, so its own entry points do not reach them.
# Duplicating one in the plugin is not merely wasteful: it mutates a private
# ref that the compiler never reads, so the extension would register into the
# void.
# The rest are ordinary compiler definitions that nothing the compiler's own
# entry points reach happens to use.
FStarC.Parser.AST.Util.register_extension_parser
FStarC.ToSyntax.ToSyntax.register_extension_tosyntax
