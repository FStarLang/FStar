# Entry points for the Custard build of the F* compiler.
#
# Custard compiles exactly what is reachable from its roots (doc/ref/custard.md
# section 4.4).  `FStarC.Main.main' is passed by the build; everything here is
# a root for one of two reasons.
#
#   - It is a *callee of a hand-written realization*.  The .ml files in src/ml
#     are outside the extracted program, so nothing Custard can see reaches
#     what they call, and a type they mention is unfolded rather than emitted
#     unless it is named here (section 8.2, section 12.9).
#
#   - It is a *module* rather than a definition, which loads the module and
#     takes its initializers as roots.  That is the only way to reach a module
#     that exists purely for its side effects (section 4.4).
#
# Blank lines and lines starting with `#' are ignored.  Keep each group sorted:
# the order has no effect on the output, only on how easy this file is to read.
